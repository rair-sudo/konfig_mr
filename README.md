# Эмулятор UNIX-оболочки

Консольный учебный эмулятор UNIX-команд на Python 3.10+. Этап 3:
интерактивный цикл, аргументы в кавычках, заглушки `ls`, `cd`, команда
`exit`, конфигурация, стартовый скрипт и CSV виртуальной файловой системы.
Приглашение использует настоящее имя пользователя и компьютера.

## Запуск и тесты

Сборка и сторонние зависимости не нужны:

```sh
./run.sh --vfs vfs/deep.csv --script scripts/stage3.txt
python3 -m unittest discover -s tests -t . -v
```

## Конфигурация

- `--vfs ПУТЬ` — расположение CSV-файла VFS. Если не задан или файл не
  удалось прочитать, используется пустая VFS; ошибка отображается.
- `--script ПУТЬ` — стартовый UTF-8 скрипт с одной командой на строку.

При запуске отображаются оба параметра. В скрипте пустые строки и строки,
начинающиеся с `#`, пропускаются. Ввод и результат видны в консоли. Ошибки
показываются с номером строки, после них выполняются следующие команды.
После скрипта открывается интерактивный режим, если не выполнена `exit`.
Проверка параметров: `scripts/test_config.sh` или `scripts/test_config.bat`.

## VFS

UTF-8 CSV с заголовком `path,type,content` загружается в память. Пути
абсолютные, `type` равен `dir` или `file`; содержимое файла — base64,
содержимое папки пусто. Недостающие промежуточные папки создаются в памяти.
Исходный CSV после чтения не изменяется. Служебная команда `vfsinfo`
показывает имя VFS, число папок и файлов. Примеры: `vfs/minimal.csv`,
`vfs/several.csv` и `vfs/deep.csv`. Проверка: `scripts/test_vfs.sh` или
`scripts/test_vfs.bat`.
