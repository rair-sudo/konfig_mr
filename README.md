# Эмулятор UNIX-оболочки

Консольный учебный эмулятор UNIX-команд на Python 3.10+. Первый этап:
интерактивный цикл, разбор аргументов в кавычках, заглушки `ls`, `cd`,
команда `exit` и обработка ошибок. Приглашение использует имя текущего
пользователя и имя компьютера.

## Запуск и тесты

Сборка и сторонние зависимости не нужны:

```sh
./run.sh
python3 -m unittest discover -s tests -t . -v
```

Пример диалога:

```text
user@host:~$ ls "два слова"
ls: ['два слова']
user@host:~$ неизвестная-команда
неизвестная-команда: command not found
user@host:~$ exit
```

## Конфигурация и стартовый скрипт

- `--vfs ПУТЬ` — расположение CSV-файла VFS. На этом этапе параметр
  отображается в отладочном выводе; подключение VFS предусмотрено далее.
- `--script ПУТЬ` — стартовый UTF-8 скрипт с одной командой на строку.

При запуске отображаются оба параметра. В скрипте пустые строки и строки,
начинающиеся с `#`, пропускаются. Ввод и результат видны в консоли. Ошибки
показываются с номером строки, после них выполняются следующие команды.
После скрипта открывается интерактивный режим, если не выполнена `exit`.
Проверка параметров: `scripts/test_config.sh` или `scripts/test_config.bat`.
