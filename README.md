# Эмулятор UNIX-оболочки

Учебное консольное приложение на Python 3.10+, использующее виртуальную
файловую систему (VFS) в памяти. Доступны `ls`, `cd`, `head`, `cal`,
`vfsinfo` и `exit`. Приглашение содержит имя пользователя, компьютера и
текущий каталог VFS. Ввод разбирается с поддержкой кавычек и экранирования.

## Запуск и тесты

Сборка и сторонние зависимости не нужны:

```sh
./run.sh --vfs vfs/deep.csv --script scripts/stage4.txt
python3 -m unittest discover -s tests -t . -v
```

Параметры `--vfs ПУТЬ` и `--script ПУТЬ` необязательны. При запуске
показывается конфигурация. Без VFS или при ошибке загрузки используется
пустая VFS. Стартовый UTF-8 скрипт выполняется построчно: отображает ввод
и вывод, пропускает пустые строки и комментарии `#`, сообщает номер
ошибочной строки и продолжает работу. После него запускается REPL, если
не выполнена `exit`.

## Команды

- `ls [-a] [-l] [--] [путь...]` — список файлов и каталогов; `-a`
  включает скрытые имена, `-l` — тип и размер (для каталога число записей).
- `cd [--] [путь]` — переход по абсолютному или относительному пути;
  без аргумента переход в корень VFS.
- `head [-n N] [--] файл...` — первые N строк; по умолчанию 10.
  Отрицательное N означает вывести всё, кроме последних |N| строк.
  Двоичные данные декодируются как UTF-8 с заменой ошибок; stdin недоступен.
- `cal [год]` или `cal месяц год` — календарь; без аргументов текущий
  месяц. Годы 1–9999, неделя начинается с воскресенья.
- `vfsinfo` — имя VFS и число файлов и папок. `exit` — завершение.

## VFS

UTF-8 CSV с заголовком `path,type,content` загружается в память. Пути
абсолютные, `type` равен `dir` или `file`; содержимое файла — base64,
содержимое папки пусто. Недостающие промежуточные папки создаются в памяти.
Исходный CSV после чтения не изменяется. Примеры: `vfs/minimal.csv`,
`vfs/several.csv` и `vfs/deep.csv`; сценарии `scripts/test_vfs.sh` и
`scripts/test_vfs.bat` проверяют все варианты. Параметры проверяют
`scripts/test_config.sh` и `scripts/test_config.bat`.
